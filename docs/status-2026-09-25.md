## 사람이 확인해야 하는 것

자동 점검으로는 확인할 수 없는 항목이다.

| 항목 | 확인 방법 |
|---|---|
| 캐릭터 드래그 | 캐릭터를 마우스로 끌어 옮기기 |
| 영역 캡처 → 풀이 | `Ctrl+Shift+S` → 문제 영역 드래그 (텍스트 풀이 경로는 자동 점검됨) |
| 실제 마이크 음성 대화 | `Ctrl+Shift+Space` → 말하기 → 대답 후 자동으로 다시 듣는지 |
| 실제 웹캠 졸음 감지 | 설정 → 졸음 감지 켜기 → 5초 보정 → 눈 감고 고개 숙이기. 오탐률은 실사용 트레이스(`record_trace`)로 재측정 필요 |
| VRM 1.0 아바타 | VRM 1.0 파일 불러오기 (0.x는 확인됨) |
| 설치 파일 | 클린 Windows PC 또는 VM에서 설치 → 모델 받기 → 첫 풀이 (목표 10분) |

## 알려진 제한

- 한국어 TTS는 화자 1명(MeloTTS)이며 남성 목소리는 피치·포먼트 후보정으로 만든다. 약간의 보코더 질감이 있다. 상업 이용 가능한 한국어 다화자 모델은 추가 조사가 필요하다.
- 음성 인식은 CPU에서 돈다 (CTranslate2 CUDA는 NVIDIA 라이브러리 라이선스 검토 필요). large-v3는 문장당 약 3.6초.
- 서술형·"몇 개" 유형은 SymPy로 검증하지 못해 최대 `medium`.
- 스캔 PDF(글자 층 없음)는 색인하지 않는다.
- Electron은 Chromium의 FFmpeg(LGPL, 동적 링크)를 포함한다. 백엔드 번들에서는 PyAV·OpenCV의 FFmpeg를 뺐다.
- 기본 캐릭터 이용 약관상 정치·종교 발화는 안전 필터로 막는다 (`solve/safety.py`).
- 백엔드는 Nuitka 대신 임베디드 CPython으로 배포한다. Nuitka 4.2.2 standalone에서 torch 2.14가 import 중 abort한다 (`build_backend.py`는 남겨 둠). 결과적으로 백엔드 코드는 .py/.pyc로 포함된다.
- 설치 파일은 코드 서명이 없어 Windows SmartScreen 경고가 뜬다.

## 성능 문제와 해결 기록

| 문제 | 원인 | 해결 |
|---|---|---|
| 츠쿠요미짱 5~17fps | Emscripten이 매 프레임 `getParameter(SCISSOR_TEST)`로 GPU 동기 대기 + 머리카락 등 94개 스키닝 패스 | 셸에서 WebGL 시저 상태 셔임 설치, 같은 재질 표면 병합(94→19) |
| 유휴 CPU 코어 1.4개 | 웹 빌드의 `Engine.max_fps`가 `usleep` busy-wait | 웹에서는 max_fps 대신 페이지 rAF 상한(60/30fps) |
| 240Hz 모니터에서 240fps | rAF가 주사율을 따름 | 같은 rAF 상한 |
| 판서 중 캐릭터가 보드에 가려짐 | HTML 레이어가 캔버스 위 | 반투명 유리 보드 + 필기 선두를 따라 캐릭터 이동 (팔 도달 거리: 기울이지 않고 ~65px, 옆으로 기울여 100~110px) |
| 첫 줄의 `=` 정렬이 어긋남 | 손글씨 폰트가 첫 사용 때 로드되어 대체 폰트 폭으로 측정 | `document.fonts.ready` 후 전체 줄 재측정 |
